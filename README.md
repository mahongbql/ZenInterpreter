# ZenInterpreter 使用指南与注意事项

感谢您下载并使用 **ZenInterpreter** 实时语音同传翻译软件！  
为了帮助您获得最佳的使用体验，请在首次运行前仔细阅读以下说明。

---

## 一、 软件安装说明 (macOS)

1. 双击打开下载的 `ZenInterpreter.dmg` 镜像文件。
2. 将 `ZenInterpreter.app` 图标拖拽至 `Applications` (应用程序) 文件夹中。
3. **首次启动如提示“无法验证开发者”或“应用已损坏”：**
   * 请前往 **【系统设置】** → **【隐私与安全性】** → 下拉至底部点击 **【仍要打开】**。
   * 或打开**终端 (Terminal)** 执行以下命令解除隔离防护：
     ```bash
     xattr -cr /Applications/ZenInterpreter.app
     ```

---

## 二、 首次启动与加载说明（重要）

1. **本地 AI 语音识别引擎加载：**
   * ZenInterpreter 内置了完整的 SenseVoice 高精度本地语音识别模型（离线部署）。
   * 软件启动时需将模型载入内存，受设备性能影响，首次打开及初始化加载约需 **5 ~ 15 秒**。在此期间界面可能会短暂响应较慢，此属正常现象，请耐心等待。

2. **账号与激活鉴权验证：**
   * 软件在启动时会自动进行云端许可及账号鉴权验证。
   * **请确保您的设备在启动阶段保持网络连接畅通。**
   * 验证过程通常需要 **1 ~ 3 秒**，验证完成后即可开启实时同传体验。

---

## 三、 音频采集配置说明（系统声音/播放视频/线上会议）

macOS 出于隐私安全考虑，默认不允许软件直接抓取“系统内部播放的声音”（如网课、线上会议、视频音频等）。若您需要同传系统播放的声音，请按照以下步骤配置：

1. **麦克风权限授权：**
   * 首次运行软件时，系统会弹出“麦克风权限请求”，请务必点击 **【允许】**。

2. **配置虚拟音频设备（Loopback Sound Device）：**
   * 若需捕获系统内部声音，建议安装免费开源的虚拟声卡驱动（如 **BlackHole** 或 Soundflower）：
     * **步骤 A：** 下载并安装 BlackHole（推荐 2ch 版本）。
     * **步骤 B：** 打开 Mac 上的 **【音频 MIDI 设置】** 应用（可通过 `Command + 空格键` 搜索打开）。
     * **步骤 C：** 点击左下角 **【+】** 号，选择 **【创建多输出设备】**。
     * **步骤 D：** 勾选您的 **【Mac 内置扬声器/耳机】** 以及 **【BlackHole 2ch】**，这样您在听到声音的同时，系统会将声音同步路由给软件。
     * **步骤 E：** 在 Mac 系统 **【设置】** → **【声音】** → **【输出】** 中，选择刚创建的 **【多输出设备】**。
     * **步骤 F：** 在 ZenInterpreter 的“输入设备”下拉菜单中选择 **【BlackHole 2ch】** 作为音频来源即可。

## 四、 核心功能与使用建议

1. **实时同传体验：**
   * 软件支持语音活动检测 (VAD) 断句与动态实时修正，降低识别误差。
   * 建议在相对安静的环境或使用清晰的音频来源，以获得更准确的识别与翻译效果。
